## 2. Deskripsi Aplikasi

### Nama Aplikasi
**Sistem Perpustakaan Digital Kampus**

### Tujuan
Sistem Perpustakaan Digital Kampus adalah aplikasi berbasis web yang dikembangkan menggunakan Laravel 12. Aplikasi ini bertujuan untuk membantu pengelolaan data perpustakaan seperti data buku, anggota, serta transaksi peminjaman dan pengembalian buku.


## 3. Perbedaan Model, View, Controller
Model bertugas mengelola data dan berhubungan dengan database. View bertugas menampilkan informasi atau tampilan yang dilihat oleh pengguna, sedangkan Controller bertugas mengatur alur proses aplikasi dan menjadi penghubung antara Model dan View.
